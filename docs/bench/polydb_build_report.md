读法：
- **检索面**（交互检索真正要读的）= `peaks_d` + `peaks_i` + `bins` + `elem`
  ≈ **50.1 MB**，且是 mmap 按需读，检索一次只碰几 MB。
- **精修面**（`sites.bin` + `sites_off`）只在命中相进精修时才读对应那几条。
- `index.sqlite` 18.8 MB 是条目元数据（公式/空间群/晶胞/密度/元素/CIF 相对路径），
  补齐 100 条候选展示字段时才查。
